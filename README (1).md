# Rare-Variant Genetics of Organ Aging

This repository contains the analysis code used in the study of the genetic architecture of organ-specific biological aging, with a particular focus on rare genetic variants.

## Code structure

- `01_bag_model/`  
  Construction of organ-specific biological age gap (BAG) phenotypes.

- `02_bhr/`  
  Bivariate heritability analyses of organ-specific BAG phenotypes.

- `03_gene_set_burden/`  
  Gene-set burden analyses.

- `04_saige_gene/`  
  Rare-variant gene-based association analyses using SAIGE-GENE+.

- `05_common_variant_conditioning/`  
  Conditional analyses accounting for common-variant associations.

- `06_functional_similarity/`  
  Functional similarity and protein-protein interaction network proximity analyses.

- `07_phewas/`  
  Phenome-wide association analysis of identified genes.

- `08_age_expression/`  
  Age-related gene expression, pathway activity, and co-expression network analyses.

- `09_cross_organ_network/`  
  Cross-organ protein interaction network and functional enrichment analyses.

- `10_proteomics_mr/`  
  Plasma protein association and Mendelian randomization analyses.
